# Hardware Safety Checklist

Before any hardware RL test:

- Verify encoder signs and units.
- Verify actuator command saturation.
- Verify emergency stop access.
- Verify software termination thresholds.
- Run sensor logging without control.
- Run actuator command test at very low amplitude.
- Run classical baseline before RL.
- Enable RL only inside the approved near-upright state range.
- Save logs for every trial.
