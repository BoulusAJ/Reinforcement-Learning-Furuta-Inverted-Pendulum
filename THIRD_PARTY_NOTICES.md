## Drehpendel Firmware

The complete Nucleo firmware is maintained separately at:

```text
https://github.com/altb71/drehpendel/tree/dev_altb
```

This repository contains RL export and integration work intended for a future
branch of that project. Access to create the branch is pending.

The small MATLAB support set under `deployment/sldrt/support/` was selected from
the `drehpendel` reference material used during this project. Check the source
repository and ZHAW project ownership before redistributing those files outside
this repository.

MATLAB, Simulink, Simulink Real-Time, and Reinforcement Learning Toolbox are
products of The MathWorks, Inc. They are required to run parts of this project
but are not distributed by this repository.

Saved MAT agents and Simulink models require compatible MathWorks products to
